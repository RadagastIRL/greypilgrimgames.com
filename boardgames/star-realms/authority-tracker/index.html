How to Play

Setup

Choose the number of players (1–4), select a faction color for each, and set the starting authority (default: 50). Tap START when you're ready.

Adjusting Authority

Each player's tile is split into two tap zones. Tap the left half to decrease authority and the right half to increase it. Hold either side down for rapid changes. A flash confirms each tap.

2-Player Mode

In a 2-player game the second player's tile is rotated 180° so both players can read their score from across the table. The tap zones flip accordingly, so left/right always feels natural from each player's perspective.

Authority Warnings

When a player drops to 50% or below their starting authority, their score turns yellow. At 25% or below it turns red and blinks — a warning that elimination is near.

End Turn

Tap ▶ End Turn to advance to the next player. Eliminated players are automatically skipped. The turn counter increments with each active player change.

Elimination & Winning

When a player's authority reaches 0 they're marked as eliminated. When only one player remains, the winner screen appears. Tap Continue to keep the board visible.

Undo

The ↩ Undo button reverses the last authority change, including eliminations. Up to 50 changes can be undone. Keyboard shortcut: Ctrl+Z (or ⌘Z on Mac).

Stats & Export

Tap 📊 Stats to view an authority chart over time, a full change log, or a per-turn table. Export the chart as a PNG or the data as a CSV.

Settings ⚙

Change the step size (how much each tap adjusts authority), start a new game keeping the same players and colors, or return to the full setup screen.
