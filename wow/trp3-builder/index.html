  1. Close World of Warcraft completely — if WoW is running when you replace the file, it will overwrite your changes on logout.
  2. Find your SavedVariables folder. The path depends on your OS and game version:
    Windows (Retail): C:\Program Files (x86)\World of Warcraft\_retail_\WTF\Account\YOUR_ACCOUNT\SavedVariables\ Windows (Classic): C:\Program Files (x86)\World of Warcraft\_classic_\WTF\Account\YOUR_ACCOUNT\SavedVariables\ Mac (Retail): /Applications/World of Warcraft/_retail_/WTF/Account/YOUR_ACCOUNT/SavedVariables/
  3. Drop the exported totalRP3.lua into that folder, replacing the existing file. Back up the original first if you have other profiles you want to keep.
  4. Launch WoW and log in. TRP3 will load your profile automatically. If you had other profiles in the old file and replaced it, you'll need to re-export with those profiles included — or use the Import button here to bring them in first.

TRP3 Profile Builder — Help

Getting started

Fill in the Basics tab, then add your story in About sections. Click Export .lua when done and follow the install guide below the editor to put the file in the right place.

Tabs

  • Basics — name, title, physical traits, icon, colour, RP status
  • Personality — trait sliders (e.g. Cheerful ↔ Melancholic)
  • About — freeform sections with titled blocks and colour markup
  • Custom Fields — pronouns, nickname, occupation, house/clan and any other custom key/value pairs
  • Misc / OOC — out-of-character notes, RP preferences, content limits

Markup / formatting

Use the toolbar in About and Misc sections to insert tags:

  • {h1}Heading{/h1} — large heading (add :c or :r for centre/right)
  • {h2}Subheading{/h2} — medium heading
  • {h3}Small heading{/h3}
  • {col:ff7c0a}orange text{/col} — coloured text
  • |cffFF7C0Aorange|r — WoW-style colour code (same result)
  • {link*https://example.com*Link text} — hyperlink
  • {icon:inv_misc_book_09:20} — inline icon at 20px

All tags must be properly opened and closed or the text may break for other viewers.

Character–Realm field

This must exactly match your in-game character name and realm with no space between name and hyphen — e.g. Aelindra-Silvermoon. Case matters. This is how TRP3 links the profile to your character.

Import & Export

  • Click Import .lua to load an existing totalRP3.lua from your computer
  • If the file has multiple profiles you'll be asked to pick one
  • Click Export .lua to download the file and drop it into your SavedVariables folder (see the install guide)

Tips from the community

  • Keep the About sections scannable — bullet points beat walls of text
  • The OOC section is expected etiquette on RP realms — state your preferences
  • Keep "Currently" updated; it's how people know you're approachable right now
